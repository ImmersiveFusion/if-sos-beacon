# Code of Conduct: the channel rules

sos-beacon finds public conversations and posts a **pointer** into a channel. A
human then decides whether to engage, and if they do, they engage **as
themselves**. The tool never replies; people do. That only stays honest, and
only stays welcome in the communities it watches, if the humans on the
receiving end of a beacon follow these rules.

These are the operating rules for anyone responding in a beacon's channel. They
are not aspirational; they are the price of running one of these channels
without becoming the thing this project exists to oppose.

## The rules

1. **React 🙋 to claim. One responder per thread, ever.** The first raised hand
   owns it. Nobody else piles on.

2. **Reply as yourself. No AI-generated or AI-drafted responses.** The beacon
   finds the conversation. *You* have it. If you can't write it in your own
   words, don't claim it.

3. **Never upvote each other's comments or the thread. Not once.** Coordinated
   voting is brigading. Zero exceptions.

4. **Disclose affiliation if you have one.** If you work on or benefit from the
   thing you're recommending, say so plainly.

5. **It is always OK to help without mentioning a product.** That is how an
   account earns the right to mention one later. Helpfulness first, always.

6. **If a thread doesn't want vendors, it doesn't. Skip it.** When a
   conversation reads as hostile to being sold to, respect that and move on.

7. **Public and open source. If you're accused of shilling, link the repo.**
   Transparency is the defense. This tool is out in the open precisely so that
   there is nothing to hide.

## Why rule 2 has no tooling to enforce it

Rule 2 is enforced **socially**, through attribution (the store records who
claimed what), not by software. That is deliberate. The moment a machine drafts
the reply, this stops being a tool that helps a human show up and becomes the
automated-outreach spam it was built to be the opposite of. The type system
already refuses to draft prose (there is no path from a classification to a
posted reply); rule 2 asks you to hold the same line with your own hands.

## Scope

This document governs conduct **in the channels a beacon feeds**. For conduct
while contributing to this repository, see the code-of-conduct section of
[`CONTRIBUTING.md`](CONTRIBUTING.md).
